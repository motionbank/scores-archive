Motion Bank Scores - missing / inaccessible Vimeo sources
Generated 2026-11-17 (fourth revision). All 465 distinct vimeo-id values
referenced by the score cells (dh 130 / jbmf 294 / two 41) were re-collected
from scratch: the media volume was lost with an external drive, so the
published archive was re-extracted and every video re-fetched via the Vimeo
API using Motion Bank account-owner credentials (yt-dlp alone hits the same
bot-gating as in November; the API sees past it for videos the account owns).

Result: 443 of 464 real videos downloaded locally - progressive files[]
renditions (the streaming-safe encodes), all verified H.264 and faststart
(moov before mdat; 276 were remuxed losslessly with
`ffmpeg -c copy -movflags +faststart`). 21 videos unavailable, 1 junk id.

The 21 unavailable videos are NOT owned by the Motion Bank Vimeo account:
they belong to "ACCAD OSU" (Ohio State University - the /two score partner
that hosted those recordings). They are public (view: anybody, embed:
public) but have download disabled, and the Vimeo API only exposes
progressive file links to a video's owner, so even the account token gets
files: [] for them. Bot-gated tools (yt-dlp with browser impersonation)
recover some public videos but 401 on these; the same gating is why they
failed the November probe. 20 other third-party videos (19 ACCAD OSU +
1 "Elsie Management") were recoverable through the player URL and are local.

For these 21 the local player bridge (modules/vimeo/local/) falls back to
embedding the real player.vimeo.com iframe - exactly what the original
site did for everyone, and visitors still see them play from Vimeo. No
other external requests exist anywhere in the scores.

If Motion Bank obtains the files from ACCAD OSU (or upload permission on
their account), drop them into media/vimeo/<id>.mp4 (H.264 mp4, faststart,
e.g. `ffmpeg -i src -c copy -movflags +faststart out.mp4`) - no code
changes needed, the bridge picks them up automatically.
